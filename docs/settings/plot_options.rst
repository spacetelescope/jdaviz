************
Plot Options
************

This plugin gives access to per-viewer and per-layer plotting options. 

To access all of the different display settings for an image viewer, click the
|icon-gear| icon in the viewer toolbar.
Changing the display settings **does not** change the underlying data, only the
visualization of that data.

.. _settings-plot_options-api:

API Access 
==========

If you wish to access plot options via API
(also see `~jdaviz.configs.default.plugins.plot_options.plot_options.PlotOptions`),
you can use the following generic example. More specific examples are given
later in this Section.

.. code-block:: python

    plot_options = jdaviz.plugins['Plot Options']
    plot_options.viewer = 'Image'
    plot_options.image_colormap = 'Plasma'
    plot_options.stretch_function = 'Arcsinh'
    plot_options.stretch_vmin = 0.05
    plot_options.stretch_vmax = 1.0

Settings
========

Plot option settings vary for the type of dataset.  Below we list the general settings for all viewers and then split the settings 
by viewer type. 

.. _settings-plot_options-settings-viewer:

Viewer
------
This option allows you to select which viewer for which you are changing the plot settings. 

.. _settings-plot_options-settings-viewerbounds:

Viewer Bounds
-------------

This dropdown allows you to change the plot pixel limits.  

.. _settings-plot_options-settings-dataset:

Dataset
-------

The data menu icons for each dataset in the viewer are displayed below the Color mode (descibed below).  

Toggling on the multiselect icon on the right will allow you to set plotting features for all datasets in the viewer.

The selected dataset is shown with a blue line above the icon in the UI.  All changes made to the features in the Layer tab below it will 
be applied to that dataset.  However, it might *not* be the top layer shown on the viewer. The data that is the top layer
in the viewer is indicated by an orange outline. 

If you select an dataset which is not the top layer, a blue banner appears in the plotting features indicating that the 
changes made to the layer maybe not be visible as it is not the top layer in the viewer.  Selecting ``MOVE [Image] to TOP`` will move the layer 
to the top.  *You do not have to do this if you do not want to change the layer order.*

Image, 2D Spectrum, 3D Spectrum Viewer Settings
===============================================

.. _settings-plot_options-viewer_settings-axes:

Show axes
---------
Toggle switch to indicate if the axes are visible. 

.. _settings-plot_options-viewer_settings-color:

Color mode
----------

This option allows you to choose whether to use a colormap or or a single color to visualize the image.
The colormap can be selected from a dropdown under the "Image" section. 

In "Color" mode, the color can be chosen from a color picker under "Image Color"
within the "Image" section. The option ``ASSIGN RGB PRESETS`` also appears. This will automatically
assign colors (spanning from blue to red) to the available layers and will adjust opacity and
stretch to produce a composite color image (also known as an RGB image). You will then
be able to fine tune all options within each "Image" section.

From the API
~~~~~~~~~~~~

The colormap for just the image being displayed can be set using the Astrowidgets API:

.. code-block:: python

    viewer = jdaviz.viewers['Image']
    viewer.colormap_options
    viewer.set_colormap('Viridis')

Or it can be set using the Plugin API (in this example, the colormap is
being set for all the images at once):

.. code-block:: python

    plot_options = jdaviz.plugins['Plot Options']
    plot_options.viewer = 'Image'
    plot_options.image_color_mode = 'Colormap'
    plot_options.image_colormap = 'Viridis'

Adding Custom Colormap
~~~~~~~~~~~~~~~~~~~~~~

A custom colormap can only be added when Jdaviz is run in a notebook, not from the
command line. The custom colormap must be added to ``glue`` *before* starting Jdaviz.
The example below adds a random colormap generated by ``photutils`` into glue:

.. code-block:: python

    from glue.config import colormaps
    from photutils.utils import make_random_cmap

    randcmap = make_random_cmap(n_colors=256)
    randcmap.colors[0] = 0.  # To make your background black
    colormaps.add('photutils_cmap', randcmap)

Only after the above is done can you start Jdaviz and use the custom colormap:

.. code-block:: python

    jdaviz.load('myimage.fits', format='Image')
    jdaviz.default_viewer.set_colormap('photutils_cmap')

Opacity

Change the translucence of the image.

Contrast
--------

Change the luminance of the color in the image.

.. _settings-plot_options-viewer_settings-bias:

Bias
----

Set a constant to subtract from every point in the data array before
applying the conversion between data value and displayed pixel saturation.
The :guilabel:`bias` slider center position is 0 bias, such that a user can apply negative
bias values by sliding it left.

.. _settings-plot_options-viewer_settings-stretch:

Stretch
-------

The Stretch Function
(see `Image stretching and normalization <https://docs.astropy.org/en/stable/visualization/normalization.html>`_)
allows you to change the equation that is used to convert data values between
:guilabel:`min` and :guilabel:`max` to the 0 to 1 scale of pixel saturation on the
image. The "Stretch Percentile Preset" can be used to set the :guilabel:`min` and :guilabel:`max`
values based on percentiles of the data.
An interactive histogram is available. It shows vertical lines representing
the ``stretch_vmin`` and ``stretch_vmax`` values, and a colorbar on top.
The stretch "curve" is plotted on the histogram to represent
how pixel values are mapped to the colorbar and can be toggled on and off in the plugin.
The collapsed menu "More Stretch Options"
includes a toggle to limit the histogram to the current zoom limits (which is not on by default)
and fields to set :guilabel:`min` and :guilabel:`max` manually.

From the API
~~~~~~~~~~~~

The stretch function for just the image being displayed
(the acceptable values are as defined by ``glue`` backend) can be set using
the Astrowidgets API:

.. code-block:: python

    viewer = jdaviz.viewers['Image']
    viewer.stretch_options
    viewer.stretch = 'sqrt'

Or it can be set using the Plugin API for a single image or all the images at once
(the acceptable values are the same as the GUI menu options
and can be accessed with ``plot_options.stretch_function.choices``):

.. code-block:: python

    plot_options = jdaviz.plugins['Plot Options']
    plot_options.stretch_function = 'Square Root'


The stretch curve on the histogram can also be toggled using the Plugin API:

.. code-block:: python

    plot_options = jdaviz.plugins['Plot Options']
    plot_options.stretch_curve_visible = True


The percentile for just the image being displayed can be set
using the Astrowidgets API:

.. code-block:: python

    viewer = jdaviz.viewers['Image']
    viewer.cuts = '95%'  # Preset
    viewer.cuts = (0, 1000)  # Custom

Or it can be set using the Plugin API for one image or all the images at once:

.. code-block:: python

    plot_options = jdaviz.plugins['Plot Options']

    # Preset
    plot_options.stretch_preset = '95%'

    # Custom
    plot_options.stretch_preset = 'Custom'
    plot_options.stretch_vmin = 0
    plot_options.stretch_vmax = 1000

.. _settings-plot_options-viewer_settings-contour:

Contour
-------

This option selects whether to show or hide contours. It is off by default and can be
turned on by clicking the eye icon. The :guilabel:`Contours` of a second image can
be plotted over a first image or cube. The contours of the second image will appear
superimposed on the first image. If contours are overplotted on a cube, the contours
will remain unchanged as you scrub through the cube. Please note that this feature is in
development and will be improved in the future.


.. _settings-plot_options-1dspec_settings:

1D Spectrum Viewer Settings
===========================

Plot uncertainties
------------------
Toggle on to view uncertainties attached to the spectrum, if any.

Show Line
---------
Toggle switch to indicate if the data layer is visible. 

Line Color
----------
Click the color picker to change the dataset color. 

Line Width
----------
Width of the line for the spectrum in pixels. Larger values are thicker lines on the plot.

Line Opacity
------------
Opacity of the line. Maximum (1) is fully opaque and minimum (0) is fully transparent.

Plot as steps
-------------
Toggle on to view the spectrum as a continuous line or a step function.

From the API 
------------
Here is an example on how to set the plot options from the API.

.. code-block:: python

   plot_options = jdaviz.plugins['Plot Options']
   plot_options.viewer = '1D Spectrum'
   plot_options.line_color = 'blue'
   plot_options.line_width = 3
   plot_options.uncertainty_visible = True

.. _settings-plot_options-scatter_settings:

Scatter Viewer Settings
===========================

Show axes
---------
Toggle switch to indicate if the axes are visible. 

Xatt / Yatt 
-----------
Select the dropdowns to change the X and Y quantities being plotted. 


Show Scatter Layer
------------------
Toggle switch to indicate if the dataset is visible. 

Show Line
---------
Toggle switch to indicate if the data layer is visible. 

Fill Marker
-----------
Toggle switch to indicate if the markers are filled. 

Opacity
------------
Opacity of the markers. Maximum (1) is fully opaque and minimum (0) is fully transparent.

Size Mode
---------

Sets the mode of the markers: ``Fixed`` or ``Linear``

Size 
----

Sets the marker size

Scale 
-----

Sets the scale of the marker

Color Mode
----------

Sets the colormapping of the markers:
   
- ``Fixed``: every marker is the same color 

Color
~~~~~
Click the color picker to change the marker color. 

- ``Linear``: the markers vary based on colormap mapped to specific column values

Column 
~~~~~~
Column to scale the chosen colormap for the ``Linear`` color mode

Colormap 
~~~~~~~~
Colormap to use for the ``Linear`` color mode

vmin / vmax 
~~~~~~~~~~~
Vmin and vmax for the ``Linear`` color mode

From the API 
------------
Using the Plugin API (in this example, the color is
being set for all the scatter points at once):

.. code-block:: python

    plot_options = jdaviz.plugins['Plot Options']
    plot_options.viewer = 'Scatter'
    plot_options.layer = 'Catalog'
    plot_options.marker_opacity = 3
    plot_options.marker_size = 7
    plot_options.marker_size_scale = 10
    plot_options.marker_color_mode = 'Fixed'
    plot_options.marker_color = '#ff00ff'

.. _settings-plot_options-histogram_settings:

Histogram Viewer Settings
===========================

Histogram Options 
-----------------

Dropdown to adjust histogram axes 

X Log Scale / Y Log Scale 
~~~~~~~~~~~~~~~~~~~~~~~~~

Toggle switches to use log axes

Number of Bins
~~~~~~~~~~~~~~

Set the number of bins in the histogram. 

Histogram X Min / X Max 
~~~~~~~~~~~~~~~~~~~~~~~
Set the x-axis minimum and maximum. 

Cumulative
~~~~~~~~~~
Toggle switch to show a cumulative histogram. 

Normalize
~~~~~~~~~

Toggle switch to normalize the histogram.

Update Bins on Reset Limits 
~~~~~~~~~~~~~~~~~~~~~~~~~~~
Toggle switch to change the bins if the limits are reset.  

Show axes
---------
Toggle switch to indicate if the axes are visible. 

Xatt 
----
Select the dropdowns to change the X quantity being plotted. 

Show Histogram Layer
--------------------
Toggle switch to indicate if the dataset is visible. 

Opacity
-------
Opacity of the histogram. Maximum (1) is fully opaque and minimum (0) is fully transparent.

Color
-----
Click the color picker to change the marker color. 

From the API 
------------
Using the Plugin API (in this example, the y-axis is in log scale and normalized, and color is
being set):

.. code-block:: python

    plot_options = jdaviz.plugins['Plot Options']
    plot_options.viewer = 'Histogram'
    plot_options.layer = 'Catalog'
    plot_options.hist_ylog = True 
    plot_options.hist_normalize = True
    plot_options.hist_opacity = 3
    plot_options.hist_color = '#ff00ff'
