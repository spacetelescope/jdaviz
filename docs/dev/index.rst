Features under dev-flags
========================

The pages below document features that are available only when their
corresponding application developer flag is enabled. They are intentionally
excluded from the user-facing indexes and landing-page cards while under
development.

To promote a feature to the main documentation, remove the page's
``:dev-only: true`` metadata, remove it from the developer toctree below, and
add it to the appropriate user-facing toctree (and any overview list) in the
loader or plugin indexes. Removing the metadata also makes the page eligible
for the landing-page cards generated by ``docs/conf.py``.
