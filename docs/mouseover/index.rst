*********
Mouseover
*********

The mouseover functionality provides real-time information about the data directly 
below your cursor. As you move your mouse across the viewer, relevant data values, 
coordinates, and metadata are displayed.

.. note::
   This feature is available in Image, Spectrum, Table, and profile viewers and provides context-specific information 
   based on the viewer type and loaded data.

Overview
========

Mouseover functionality provides real-time information about data as you move your cursor across viewers:

* **Image Viewer**: Display pixel coordinates, values, and WCS information
* **Spectrum Viewer**: Display wavelength and flux values at cursor position
* **Table Viewer**: Show row data and column values under the cursor
* **Profile Viewer**: Show profile values along the cursor position

.. note::
   Mouseover information is not available for **Scatter Viewers** and **Histogram Viewers**.
